Monkey Viewer 1.0 - Third-party components
=========================================

Monkey Viewer bundles the components below. Their full licence texts are installed with the program in the
"licenses" folder (Windows: C:\Program Files\Monkey Viewer\_internal\licenses; macOS: inside the app bundle,
Contents/Resources/licenses). The exact versions are recorded in requirements-lock.txt and in the
machine-readable software bill of materials (MonkeyViewer-<version>-sbom.cdx.json, CycloneDX 1.6) published
with every release.

Notes
-----
* AGPL-3.0 (PyMuPDF / MuPDF): see LICENSE.txt, section 3. The source code of the exact versions is available
  at the links above (release tags matching the versions listed).
* LGPL-3.0 (libheif, libde265): the libraries are shipped as separate, replaceable shared libraries
  (libheif / libde265 .dll / .dylib) and are used unmodified. Source: https://github.com/strukturag/libheif
  (v1.18.1) and https://github.com/strukturag/libde265 (v1.0.15).
* PyInstaller's bootloader exception allows distributing the generated program under any licence.
