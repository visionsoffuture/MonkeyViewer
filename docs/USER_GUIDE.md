# Monkey Viewer — მომხმარებლის სახელმძღვანელო

Monkey Viewer ხსნის იმ ფაილებს, რომლებსაც Word, Excel ან ჩვეულებრივი PDF-მნახველი ვერ ხსნის: ნახაზებს (DWG, DXF),
რუკებს (SHP, KML, GPX), ხელმოწერილ და დაშიფრულ ფაილებს, Lua და სხვა კოდს, SVG-ს და სხვა სპეციფიურ ფორმატებს.
პროგრამა ფაილებს არსად აგზავნის; ინტერნეტს მხოლოდ ამინდის პროგნოზისთვის იყენებს.

## 1. ფაილის გახსნა

- **ორმაგი დაწკაპუნება** ფაილზე — თუ ეს ტიპი Monkey Viewer-ზეა მიბმული.
- **მარჯვენა ღილაკი → გახსნა პროგრამით → Monkey Viewer** — ნებისმიერი მხარდაჭერილი ფაილისთვის.
- პროგრამაში: **გახსნა** (Ctrl+O), ფაილის **გადმოთრევა** ფანჯარაში, ან **ფაილი → ბოლოს გახსნილი**.
- მთავარ გვერდზე კატეგორიაზე (მაგ. „CAD“) დაწკაპუნება ფაილის არჩევისას მხოლოდ ამ ტიპებს აჩვენებს.
- იგივე ფაილის ხელახლა გახსნა მას დისკიდან თავიდან ჩატვირთავს (შეუნახავ ცვლილებებზე პროგრამა ჯერ გკითხავთ).

Word / Excel / PowerPoint, ZIP / RAR, ელფოსტა და აუდიო/ვიდეო იხსნება თავისი პროგრამებით. ასეთ ფაილზე
Monkey Viewer აჩვენებს მინიშნებას და ღილაკს **ნაგულისხმევი პროგრამით გახსნა**.

## 2. მენიუები და ფანჯარა

- **ზედა მენიუს ზოლი**: ფაილი, რედაქტირება, ხედი, **დოკუმენტის საკუთარი მენიუ**, ფანჯარა, დახმარება.
  მეოთხე მენიუ გახსნილი ფაილის ტიპს მიჰყვება: PDF / DjVu — „დოკუმენტი“, DWG / DXF — „ნახაზი“, რუკა — „რუკა“,
  ცხრილი — „ცხრილი“, კოდი — „ტექსტი“, სურათი — „სურათი“, SVG — „SVG“. კლავიატურით: Alt+F, E, V, D, W, H (ან F10).
- **☰ (მარცხნივ ზემოთ)**: მთავარი, ახალი, გახსნა, ბოლოს გახსნილი, შენახვა, ბეჭდვა, კალკულატორი,
  გვერდითი პანელი, მენიუს ზოლის ჩვენება / დამალვა და ყველა მენიუ ერთ ადგილას.
- მენიუ იხსნება მხოლოდ დაწკაპუნებით; მაუსს თუ გაიტანთ, თავისით დაიხურება. Mac-ზე იგივე მენიუები ეკრანის ზედა
  ზოლშია.
- პატარა ფანჯარაში ყველაფერი ხელმისაწვდომი რჩება: მთავარი გვერდი ჩამოიწევა, ფაილების სია, PDF-ის მინიატურები
  და რუკის ფენები დროებით იმალება და ფანჯრის გადიდებისას ბრუნდება; ზოლზე დაუტეველი ღილაკები **»**-შია.
- **ხედი → სრული ეკრანი** (F11).

## 3. რომელი ფაილები გაიხსნას Monkey Viewer-ში

პირველ გაშვებაზე პროგრამა გკითხავთ. მოგვიანებით: **დახმარება → ფაილის ტიპების მიბმა**.

- **მენიუში** — Monkey Viewer გამოჩნდება მარჯვენა ღილაკის „გახსნა პროგრამით“ სიაში.
- **ძირითადი** — ორმაგი დაწკაპუნება ფაილს Monkey Viewer-ში გახსნის.
- **რეკომენდებული** ღილაკი სპეციფიურ ტიპებს მონიშნავს; მოუნიშნავი ტიპები ისე რჩება, როგორც იყო.

თუ ეს პუნქტი არ ჩანს, ფაილის ტიპებს თქვენი IT ადმინისტრატორი მართავს.

## 4. PDF

- **ხელსაწყოები** (ზედა ზოლი ან მენიუ „დოკუმენტი“): მონიშვნა, ტექსტი, რედაქტირება (არსებული ტექსტის
  შესწორება), მარკერი, კალამი, ჩარჩო, წაშლა (გათეთრება), სურათი / ხელმოწერა, ჩამოჭრა. ფერი — ფერის ველით,
  ბოლოს გამოყენებული ფერებით ან **პიპეტით** დოკუმენტიდან.
- **გვერდები**: შემობრუნება, კოპირება / ჩასმა, წაშლა, ამოღება ახალ PDF-ში, დაყოფა ფაილებად, ცარიელი გვერდის ან
  სხვა ფაილის გვერდების ჩასმა, ზემოთ / ქვემოთ გადატანა (მონიშნეთ მინიატურები).
- **ჩამოჭრა**: დახაზეთ ჩარჩო, შეასწორეთ კუთხეებით ან გადაათრიეთ, აირჩიეთ გვერდები → **ჩამოჭრა (Enter)**.
  ზუსტად: ჩაწერეთ კიდეები მილიმეტრებში, ან ამოძრავეთ ჩარჩო ისრებით (1 pt, Shift — 10 pt; Alt — ზომის შეცვლა).
  არჩევანში ჩანს, ზუსტად რომელი გვერდები მოიჭრება. სრული გვერდის დასაბრუნებლად: გვერდები → ჩამოჭრის გაუქმება.
- **შენახვა როგორც** → PNG / JPEG / TIFF / BMP: გვერდები სურათებად. PDF-ების გაერთიანება: გვერდები → გვერდების
  ჩასმა ფაილიდან.
- სურათად ქცეული ან დასკანერებული PDF-ის ტექსტი ვერ შესწორდება — მას ტექსტის ფენა არ აქვს.
- ცვლილებები ინახება **შენახვით** (Ctrl+S) ან **შენახვა როგორც** (Ctrl+Shift+S).

## 5. SVG

.svg ფაილი კოდად იხსნება. **SVG-ის გაშვება** (F5) ახალ ჩანართში აჩვენებს ნახატს და უშვებს მის ანიმაციას
(SMIL და CSS). იქ არის პაუზა / გაშვება (Space), თავიდან, გადიდება, ფონი (ჭადრაკული, თეთრი, შავი),
**PNG-ად შენახვა** და ბეჭდვა. კოდის შეცვლის შემდეგ ხელახლა F5 — გადახედვა განახლდება, შენახვა არ სჭირდება.

## 6. ნახაზები და რუკები

- **DWG / DXF**: შრეების ჩართვა-გამორთვა, ღია / მუქი ფონი, მოდელი და ფურცლები, **PDF-ად შენახვა**.
  DWG და DjVu დამატებითი პროგრამების გარეშე იხსნება (LibreDWG და DjVuLibre პროგრამას მოყვება).
- **რუკები**: ფენები (ფერის შეცვლით), ატრიბუტების ცხრილი, ობიექტზე დაწკაპუნება → მისი მონაცემები,
  **PNG ექსპორტი**.

## 7. ხელმოწერილი და დაშიფრული ფაილები

- **ხელმოწერილი PDF**: ზემოთ ზოლში ჩანს, ნამდვილია თუ არა ყოველი ხელმოწერა, შეიცვალა თუ არა ფაილი ხელმოწერის
  შემდეგ, ვინ და როდის მოაწერა ხელი. **დეტალები** ხსნის ხელმოწერების პანელს: თითო ხელმოწერა ცალკე ბარათზე —
  სტატუსი, შემოწმებები, მიზეზი, ადგილი, სერტიფიკატის დეტალები, სერტიფიკატის შენახვა და ანგარიშის კოპირება.
  **ხელმომწერის ნდობის შემოწმება** — Windows / macOS ამოწმებს გამცემ ორგანოს და გაუქმებას.
- **.p7m (ელექტრონული ხელმოწერა)**: ზემოთ ჩანს, ხელუხლებელია თუ არა ხელმოწერა და ვინ მოაწერა ხელი;
  **დოკუმენტის გახსნა** ხსნის თავად დოკუმენტს (მაგ. PDF-ს).
- **დაშიფრული ფაილი** (.enc, .crypto, .gpg, დაშიფრული .p7m): პროგრამა აჩვენებს, რით არის დაშიფრული, და
  შესაბამის ღილაკს — **პაროლით გაშიფვრა**, **GnuPG-ით გაშიფვრა** ან **ჩემი სერტიფიკატით გაშიფვრა (.pfx)**.
  გაშიფრული ფაილი იხსნება ახალ ჩანართში; დისკზე მხოლოდ მაშინ ინახება, თუ **შედეგის შენახვას** დააჭერთ.
- **სერტიფიკატი** (.cer, .pfx): ვისზეა გაცემული, ვინ გასცა, ვადა, ანაბეჭდი; **ნდობის შემოწმება**.
- თუ ფაილი მოულოდნელად დაშიფრული აღმოჩნდა (მაგ. ბევრ ფაილთან ერთად) — **არავის გადაუხადოთ**,
  დაუყოვნებლივ აცნობეთ IT სამსახურს.

## 8. ბეჭდვა

**ფაილი → ბეჭდვა** (Ctrl+P / ⌘P) ყველა დოკუმენტისთვის: PDF, DjVu, XPS, ნახაზი, ცხრილი, კოდი / ტექსტი, სურათი,
SVG და რუკა (როგორც ეკრანზე ჩანს). Windows-ზე იხსნება სისტემის ბეჭდვის ფანჯარა; Mac-ზე — Monkey Viewer-ის
ფანჯარა (პრინტერი, გვერდები, ასლები, ორმხრივი ბეჭდვა). ჰორიზონტალური გვერდი ქაღალდზე თავისით მობრუნდება.

## 9. კალკულატორი

ზედა ზოლის **÷** ღილაკი, **ფანჯარა → კალკულატორი** ან **Ctrl+Shift+K**. პატარა ცალკე ფანჯარაა: ღილაკებით ან
კლავიატურით (ციფრები, + − * / ^ ( ), Enter = , Backspace, Esc — გასუფთავება).
- ზუსტი ათწილადები (0.1 + 0.2 = 0.3), პროცენტი როგორც საოფისე კალკულატორზე (200 + 10% = 220).
- 1/x, x², √x, ±; **ისტორია** (ორჯერ დაწკაპუნება შედეგს დააბრუნებს), **კოპირება** (Ctrl+C), ჩასმა (Ctrl+V).
- ქინძისთავის ღილაკი — სხვა ფანჯრების ზემოთ დარჩეს.

## 10. ამინდი

სტატუსის ზოლის მარჯვენა კუთხეში ჩანს არჩეული ქალაქის ამინდი. დაწკაპუნებით — დღევანდელი ამინდი (ქარი,
ტენიანობა) და პროგნოზი 7 დღით (მაქსიმუმი / მინიმუმი, ნალექი). ქალაქის არჩევა — პროგნოზის ფანჯრის სათაურში
ან **ხედი → ამინდი**; იქვე ირთვება და ითიშება. მონაცემები: ნორვეგიის მეტეოროლოგიური ინსტიტუტი (MET Norway),
ახლდება ნახევარ საათში ერთხელ. ინტერნეტის გარეშე ჩანს ბოლოს მიღებული პროგნოზი.

## 12. ენა და თემა

- **ხედი → ენა**: ქართული, English ან „როგორც კომპიუტერზეა“.
- **ხედი → თემა**: „როგორც კომპიუტერზეა“ (Windows / macOS-ის ღია ან მუქი რეჟიმი), ღია ან მუქი.
- შეცვლისას პროგრამა გკითხავთ, გადაიტვირთოს თუ არა — გახსნილი ფაილები თავიდან გაიხსნება.
- თუ არჩევანი მიუწვდომელია, მას ადმინისტრატორი ადგენს.

## 13. თუ რამე არ მუშაობს

- **დახმარება → კომპონენტები და დიაგნოსტიკა** — აჩვენებს, რომელი ნაწილები მუშაობს; **ანგარიშის კოპირება** და
  **თვითშემოწმება** IT სამსახურისთვის.
- ზოგი ფუნქცია შეიძლება ორგანიზაციის პოლიტიკით იყოს გამორთული (მაგ. მხოლოდ ნახვის რეჟიმი, ბეჭდვა, ამინდი) —
  ასეთ დროს პროგრამა ამას პირდაპირ გეტყვით.

პროგრამა აღრიცხავს, რომელი ფაილი გაიხსნა, შეინახა, დაიბეჭდა, გაიშიფრა ან შემოწმდა (აუდიტის ჟურნალი).
ფაილების შიგთავსი, პაროლები და გასაღებები არასოდეს იწერება.
