Monkey Viewer — ინსტალაცია Mac-ზე
================================

1. გადაათრიეთ „Monkey Viewer“ საქაღალდეზე „Applications“ (ამავე ფანჯარაში).
2. გახსენით Applications → Monkey Viewer.

თუ Mac წერს „Monkey Viewer can't be opened“ / „Apple could not verify…“:
   System Settings → Privacy & Security → ქვემოთ „Monkey Viewer was blocked…“ → Open Anyway → Open.
   (ან Terminal-ში ერთხელ:  xattr -dr com.apple.quarantine "/Applications/Monkey Viewer.app")
   ეს ხდება მანამ, სანამ პროგრამა Apple Developer ID-ით არ არის ხელმოწერილი.

ფაილის გახსნა: ფაილზე მარჯვენა ღილაკი → Open With → Monkey Viewer.
წაშლა: Applications-იდან Monkey Viewer გადაიტანეთ Trash-ში.


Installing on a Mac
-------------------
1. Drag "Monkey Viewer" onto "Applications".
2. Open Applications > Monkey Viewer. If macOS blocks it: System Settings > Privacy & Security > Open Anyway.
